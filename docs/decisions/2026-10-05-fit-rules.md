# Fit checker: definitions the spec left open

- **Bullet -> id**: Typst metadata marks at each bullet's start (top of first line)
  and end (bottom of last line), read with `typst eval 'query(<rc-mark>)'`
  (`typst query` is deprecated in 0.15). A bullet's glyphs are those inside the
  band and right of the start mark. Tested with bullets of known length in
  shuffled order.
- **Orphan rule** applies only to bullets of 2+ lines. A one-line bullet of any
  length is fine.
- **Last-line fill** = (right edge of the last non-space glyph - bullet text
  start) / (text column right - bullet text start). Typst leaves a trailing space
  glyph on wrapped lines; spaces are ignored.
- **Page fill** = (bottom of the lowest glyph on page 1 - top margin) / (page
  height - top margin - bottom margin).
- **Rules apply to bullets**, including education fact lines. Additional
  information lines are measured and reported, not constrained.
- **Lever bounds** (defaults reproduce the default look): leading 1.8-4.0pt (2.7),
  bullet_gap 0-2 (0), role_gap 0.5-3 (1), entry_gap 3-10 (6), section_gap 6-14
  (10), line_gap 0-2 (1); vertical margins 0.5-0.75in; margin_x 0.5-0.75in (0.6);
  font 10-11pt (10.5).
- **Solver**: line breaks depend only on font and margin_x, so it walks
  (font, margin_x) candidates nearest the defaults first, font last (lever
  order). For the first candidate whose line constraints pass, it binary-searches
  one spacing scalar (every spacing lever interpolated between default and bound),
  then vertical margins, aiming for 98.5% fill on one page. If none passes it
  reports "only content can fix this" with the closest candidate's deltas.
  Content is never edited.
- **layout.yaml** holds the levers, separate from selection.yaml, so the solver
  never rewrites a file a person edits and comments survive.
- **ATS** uses only version-stable pdftotext properties (characters present;
  order after collapsing whitespace) because poppler differs between macOS and CI.
- **Title and degree lines must not wrap**: a long official degree title can wrap
  mid-phrase, which a bullet-only checker misses. The template marks each role/degree line; a
  wrap is a line failure, so the solver treats it like a 3-line bullet.
